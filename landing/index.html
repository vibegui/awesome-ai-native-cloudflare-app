The parts

Everything an AI app needs, already wired to the same Worker.

Each product is a binding: one line in wrangler.jsonc, then a typed object on env. No SDK to install, no connection string, no second vendor to sign up for. These are the ones we reach for, and what the $5 plan covers before any usage charge.

Compute

Where the code runs

V8 isolates in every Cloudflare city. No containers to size, no regions to pick.

Workflowsdurable jobs

Multi-step agent runs that survive failures.

Each step is checkpointed and retried on its own, so a report that makes five LLM calls repeats only the one that failed. Put one paid call per step.

await step.do("summarize", () => llm(page))

$5: 500k steps · 1 GB state

Queuesasync

Ack the webhook now, think later.

WhatsApp gives you 20 seconds. Push the message on a queue, answer 200, and let a consumer run the slow agent loop with retries and batching.

await env.JOBS.send({ phone, text })

State

Where memory lives

Pick by access pattern. Most apps start with D1 and KV and never need more.

D1SQL

Relational data, analytics and the agent board.

SQLite with numbered migrations. Holds users, events, goals, hypotheses and tasks. Costs nothing while idle, so one database per customer is a real option.

await env.DB.prepare("SELECT * FROM goals").all()

$5: 25B rows read · 50M written · 5 GB · 50k databases

KVkey-value

Chat threads, snapshots, dedupe keys.

Read-heavy and global. Conversation turns keyed by user and day with a TTL give an assistant long-term memory with no schema at all.

await env.THREADS.put(key, turns, { expirationTtl })

$5: 10M reads · 1M writes · 1 GB

R2objects

Files, audio, screenshots, the RAG corpus.

S3-compatible storage with no egress fee, ever. Voice notes, generated images and the markdown your AI Search index reads all live here.

await env.FILES.put(`audio/${id}.ogg`, req.body)

Free tier: 10 GB · then $0.015/GB · egress $0

Durable Objectscoordination

One live object per room, agent or document.

A single-threaded instance with its own SQLite, addressed by name. Chat rooms, presence, WebSocket hubs and per-agent sessions, hibernating when idle.

env.ROOM.get(env.ROOM.idFromName(roomId))

$5: 1M requests · 400k GB-s · 5 GB SQLite

Logs, caching, rate limits, retries and fallbacks in front of OpenRouter, Anthropic or OpenAI. Store provider keys in the gateway and the Worker holds no LLM secrets. Tag calls with metadata and the dashboard becomes your token analytics.

Scale out, not up

There is no instance to outgrow.

A Postgres instance has a size, a connection cap and a monthly price whether anyone visits or not. A Worker runs per request, and a D1 database or a Durable Object costs nothing while it sleeps. That turns "a database per customer" from a budget meeting into a design choice.

The model

The app exposes its own metrics, and agents close the gap.

Analytics, goals, memory, hypotheses, a task board and chat rooms are all MCP tools on the deployed Worker. Connect Claude Code with two committed files, .mcp.json and CLAUDE.md, and every session runs the same loop on your machine with your credentials. No server-side git tokens, no hosted brain.

Brief

get_briefing returns goals with live progress, 7-day metrics, open bets, the board and the human's latest directive.

Close old bets

Every hypothesis in testing is checked against real numbers by a different agent, told to assume it is wrong.

Pick one

Review queue first, then open tasks, then the best proposed bet: "If we change X, metric Y moves, because Z."

Build

Edit the code for that one bet. Every new surface gets track(), or the next session can't see it.

Ship

bun run check, tests, an adversarial diff review, deploy, then smoke-test production.

Record

Hypothesis to testing, task to review, a decision in memory, a handoff in #general.

analyst

Reads metrics, writes observations, files and ranks bets.

Never writes code.

builder

Claims tasks, implements, instruments, deploys.

Never grades its own work.

reviewer

Assumes it's broken. The only hat that confirms or refutes.

Never implements.

ceo

Reallocates weekly token budgets by tokens per reviewer-closed task.

Real money only from a human.
