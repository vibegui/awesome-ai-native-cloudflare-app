The skills

Six skills, each written after something broke.

The agent picks the right one from its description when the work calls for it. You don't have to remember they're there.

01cloudflare-request-budget

Before shipping anything that fetches

Write down the worst case before it bites: requests per page view when every call fails, caps and a total budget per loop, cron-built snapshots with stale-while-revalidate, short negative caching, service bindings between your own Workers, per-caller rate limits.

The smell A home page doing ~1,000 upstream reads per visit, because nobody multiplied it out.

02cloudflare-edge-caching

A page that should cache but doesn't

Cache-Control per route, cache-key hygiene, the headers and cookies that silently turn a response into no-store, single-flight dedupe and an in-memory SWR cache that stays correct.

The smell cf-cache-status says DYNAMIC on the page you thought was static.

03cloudflare-worker-memory

Error 1102 or a slower Worker after a deploy

Where the 128 MB per isolate actually goes, measuring memory per deploy, moving build-time data to KV, streaming instead of buffering.

The smell A bundled JSON file that grew quietly until the isolate fell over.

04cloudflare-egress-audit

High bandwidth, low cache hit rate

The traps that look cached in curl but miss for real traffic, trimming payloads before render and before cache, finding the one URL eating the bill.

The smell HIT in your terminal, MISS for every real visitor.

05cloudflare-waf-and-bots

Bots hammering a route, or touching WAF rules

Investigate by path, ASN, user agent and bot score; log, then challenge, then block; expiry and alerts on every automatic block; never block your own services; the Rulesets API call that wipes a whole ruleset.

The smell A partial PUT that wiped every rule on a production zone.

06worker-security-baseline

A route that spends money, holds a secret or guards /mcp

Same-origin checks with Origin and Sec-Fetch-Site, the Rate Limiting binding, SSRF allowlists for proxies, constant-time token checks that fail closed.

The smell A paid route anyone on the internet can call in a loop.
